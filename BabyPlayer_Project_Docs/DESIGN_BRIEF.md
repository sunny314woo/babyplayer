# BabyPlayer — V1 冻结设计与实现约束

> 用途：本文档记录已冻结的 V1 UI、遥控器交互与 tvOS 实现约束。
> 当前实现已扩展到 Samba/Jellyfin 双媒体源，并已完成歌词、封面、进度/续播、喜欢/屏蔽和跳过 Debug。
> 阅读顺序建议：`DEVELOPMENT_STATUS_2026-09-05.md` → `PRODUCT.md` → 本文档 → `TASK.md`。

> **V1 需求与 UI 已于 2026-07-29 冻结。最终视觉与交互事实来源为本地 `BabyPlayer_Design_Prototype/` HTML 原型，不使用此前未完成的 Figma 文件。**
> 如发现明确的 tvOS 技术限制，先说明限制，再提出最小调整方案，不重新设计 UI。

---

## 1. 项目背景

BabyPlayer 是一款面向幼儿家庭的 Apple TV 本地媒体播放器。

它不是通用文件播放器，也不是家庭媒体服务器。

核心体验：**打开 App → 看到内容 → 点击封面 → 播放**

儿童不需要理解文件、目录、服务器、网络协议等概念。

---

## 2. 设计目标

将已冻结原型准确实现为 tvOS SwiftUI 界面，并覆盖以下场景：

- 首次配置引导流程（Jellyfin Quick Connect）
- 儿童首页（两种播放模式入口）
- 焦点（Focus）状态与流转
- 播放界面（系统 AVPlayerViewController 的接入状态）
- 返回行为
- 空状态、加载状态、错误状态
- 家长设置入口与家长设置页面

实现必须保持各阶段可构建、可运行、可验证。

---

## 3. 产品原则（设计约束）

### 3.1 内容优先
首页首先展示内容，不是文件夹、服务器或设置。

### 3.2 儿童优先
大封面、少文字、少层级、少按钮、明确的焦点和点击反馈。

### 3.3 儿童化 ≠ 卡通装饰
儿童化 = 容易理解和操作。避免花哨插画、跳动图标、拟物装饰、过多颜色。

### 3.4 隐藏技术细节
不显示文件路径、服务器地址、编码格式、技术错误码等。

### 3.5 家长配置，儿童使用
低频复杂操作由家长完成，入口低调。

---

## 4. 视觉方向

### 4.1 事实来源
- **最终基准**：本地 `BabyPlayer_Design_Prototype/index.html`、`styles.css`、`app.js`
- **产品参考**：Infuse 的大封面、内容优先和清晰视觉层级
- **反向约束**：不做 VLC 式文件管理器界面

### 4.2 视觉基调
- C「绘本果园」：温柔、安心、亲子陪伴
- 桃乳白统一背景
- 白天模块使用浅杏黄和珊瑚橙
- 哄睡模块使用淡紫粉和莓果紫
- 嫩叶绿、奶油黄作为辅助色
- 大封面为视觉主角，文字信息保持最小必要量

### 4.3 字体
- Apple TV 系统字体（SF Pro）
- 首页仅显示分类名和封面标题

### 4.4 动效
- Focus 有抬升、轻微方向倾斜、柔和光晕和克制的呼吸效果
- 焦点移动时自动将封面滚入当前 shelf 的可视区域
- 白天与哄睡 shelf 严格对齐、各自独立横向滚动
- 保留轻柔遥控器声音反馈，家长可在设置中关闭

## 5. V1 页面清单与设计要点

### 5.1 首次配置引导流程（家长使用）

**流程（Jellyfin Quick Connect）**：

1. 欢迎页：一句话说明 BabyPlayer 是什么
2. 输入 Jellyfin 服务器地址（IP + 端口）
3. Apple TV 屏幕显示 6 位数字配对码
4. 家长在 Mac Jellyfin 浏览器点击批准
5. 配对成功 → 进入儿童首页
6. 配对失败 / 超时 → 明确错误提示 + 重试

**设计要点**：

- 使用 Apple TV 屏幕键盘（不自建输入）
- 错误提示用普通人语言，不显示技术错误码
- 配对成功后永久记住，家长可在设置里重新配对或清除

### 5.2 儿童首页

**核心结构**：

┌─────────────────────────────────────────────┐
│  [儿歌]  [动画]  [全部]                     │  ← 固定三个选项卡
│                                             │
│  白天模式                                    │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐            │  ← 第一行 shelf
│  └──┘ └──┘ └──┘ └──┘ └──┘ └──┘            │
│                                             │
│  哄睡模式                                    │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐            │  ← 第二行 shelf
│  └──┘ └──┘ └──┘ └──┘ └──┘ └──┘            │
│                                             │
│                                    ⚙ ← 家长入口 │
└─────────────────────────────────────────────┘

**重要语义**：两行不是简单的内容分组，而是**两种播放模式的入口**：
- 从"白天模式"行进入 → 白天模式播放器（单曲循环）
- 从"哄睡模式"行进入 → 哄睡模式播放器（总时长限制）

**内容适用性标签**：每个内容项有一个标签属性，取值为 `daytime` / `sleep` / `both`。

- `daytime` 只出现在白天模式行；
- `sleep` 只出现在哄睡模式行；
- `both` 同时出现在两行；默认值为 `both`。

Jellyfin 文件夹结构可提供初始分配，家长设置页提供手动分配兜底。未分配内容按 `both` 处理，并在首页显示温和提示，引导家长前往设置。

**设计要点**：

- 封面比例：横版 16:9
- 每个封面下最多一行标题，超出省略
- 顶部固定三个选项卡：儿歌 / 动画 / 全部；切换后两行独立过滤
- 家长入口（齿轮）右下角，尺寸小、低对比度，儿童不注意；焦点到齿轮时显示"家长设置"文字
- 遥控器上下切换在行之间跳转，左右切换在封面之间跳转
- 上箭头从第一行 shelf 顶部可以进入选项卡
- 行标题“白天模式”“哄睡模式”保持对儿童可见

### 5.3 焦点（Focus）状态

每一个可交互元素都要有明确的焦点态设计：

- 封面焦点态（缩放 + 阴影 + 高亮）
- 选项卡焦点态
- 家长入口焦点态（焦点后显示文字标签）
- 家长设置页各控件焦点态

遵循 tvOS 视差滑动效果。

### 5.4 播放界面

**技术方案**：使用 tvOS 系统 AVPlayerViewController，不自定义控制条。

**需要设计的是状态，不是按钮**：

- 播放画面状态（无 UI 覆盖）
- 系统控制条出现/隐藏状态
- 加载中状态（简单加载指示，不显示技术信息）
- 播放失败状态（儿童可理解的图标 + 家长可理解的错误说明 + 返回按钮）
- 视频自然结束的过渡状态

**两种播放模式的规则**：

- 白天模式：每首视频默认循环 3 次，家长可调整；循环次数达到后直接结束并回到首页
- 哄睡模式：默认总时长 30 分钟，家长可调整；每首曲目不循环，自然结束后自动播放下一首，达到时长或播放列表结束后回到首页
- 播放中不显示剩余时间提示

### 5.5 返回行为

| 场景 | Back 键行为 |
|------|------------|
| 播放中 | 退出到首页，Focus 恢复到刚播放的封面 |
| 首页 | 不退出 App |
| 首次引导 | 退一步；不能退出配置 |
| 家长设置页面 | 返回首页，Focus 回到齿轮 |
| 屏幕键盘输入中 | 取消输入 |

### 5.6 视频自然播放结束

- **白天模式**：当前视频循环次数达到后直接结束，回到首页，Focus 恢复到刚播放的封面
- **哄睡模式**：每首曲目不循环；当前曲目自然结束后自动播放列表下一首，每首最多一次；播放至总时长 30 分钟或列表结束后回到首页，Focus 恢复到最初进入播放的封面

白天模式不自动播放下一首；哄睡模式按上述规则自动下一首。两种模式都不显示剩余时间提示。

### 5.7 空状态（无媒体）

Jellyfin 连接成功但媒体库为空：

- 温和插画或图标
- 大图标面向儿童；小字说明面向家长："还没有内容，请家长先添加视频"
- 不给儿童无意义的操作按钮

### 5.8 分类切换后为空

选中某个分类但该分类下无内容：

- 保留顶部选项卡
- 中间显示轻量空提示，不遮挡选项卡切换

### 5.9 媒体源不可用

Jellyfin 服务器无法连接：

- 明确、温和的提示："暂时看不到内容，请稍后再试"
- 提供"重试"按钮
- 不显示技术错误码或服务器地址

### 5.10 Jellyfin 认证失效 / 重连

- 检测到失效时，引导家长重新完成 Quick Connect
- 儿童界面显示"暂时看不到内容"，家长入口可发起重新配对

### 5.11 首页首次加载中

- 骨架屏或轻量加载指示
- 不显示 loading 百分比或技术信息

### 5.12 封面加载中 / 封面缺失

- 加载中：占位背景 + 轻量骨架
- 封面缺失：由 Apple TV 端从视频画面截取生成；生成前使用默认占位图 + 标题文字（不显示"图片加载失败"）

### 5.13 横向滚动焦点保持

- 滚动到末尾不循环（到头即停）
- 分类切换后 Focus 落在新分类第一行第一个封面
- 从播放/设置返回后 Focus 恢复到进入前的位置

### 5.14 家长设置入口与设置页面

**入口**：首页右下角齿轮，低对比度、小尺寸；焦点后显示"家长设置"文字。

**设置页面结构**：

- 媒体源选择：局域网 Samba 与 Jennifer/Jellyfin 手工切换，选定项持久为下次启动默认源
- Samba 连接管理（服务器、共享名、媒体目录、账号、密码与连接测试）
- Jellyfin 连接管理（查看当前状态、重新配对、清除配对）
- 分类映射管理（Jellyfin 可映射媒体库/文件夹，Samba 可映射共享下目录；“全部”聚合两类内容）
- 内容适用性标签分配（`daytime` / `sleep` / `both`，默认 `both`）
- 白天模式默认循环次数（默认 3 次）
- 哄睡模式总时长（默认 30 分钟；曲目不循环）
- 轻柔遥控器声音反馈开关（默认开启）
- 关于 / 版本信息

设置页采用平铺列表，不分组。内容标签使用单一属性编辑，不拆成“白天内容”和“哄睡内容”两套列表。

**每个操作需要设计的状态**：

- 保存成功 / 取消
- 测试连接中 / 连接成功 / 连接失败
- 恢复默认设置的二次确认
- 儿童误进入后的安全返回路径（Back 立即回首页）

## 6. 遥控器交互总览

| 场景 | 上 | 下 | 左 | 右 | 中心键 | Menu/Back |
|------|-----|-----|-----|-----|--------|-----------|
| App 启动默认 Focus | 白天模式行第一个封面 | | | | | |
| 首页选项卡 | - | 进入第一行 shelf | 上一个选项卡（不循环） | 下一个选项卡（不循环） | 切换选项卡 | 不退出 |
| 首页第一行 shelf | 进入选项卡 | 进入第二行 | 上一个封面（不循环） | 下一个封面（不循环） | 开始播放（白天模式） | 不退出 |
| 首页第二行 shelf | 回到第一行 | - | 上一个封面（不循环） | 下一个封面（不循环） | 开始播放（哄睡模式） | 不退出 |
| 家长入口（齿轮） | 从第二行右下 Focus 可到达 | - | 回到最后一个封面 | - | 打开家长设置 | 不退出 |
| 播放中 | - | - | - | - | 暂停/继续（系统） | 退出到首页，Focus 恢复到刚播放的封面 |
| 首次引导 | 焦点上移 | 焦点下移 | 焦点左移 | 焦点右移 | 确认 | 退一步 |
| 家长设置页面 | Focus 上 | Focus 下 | - | - | 确认 | 返回首页，Focus 回齿轮 |
| 屏幕键盘输入中 | - | - | - | - | 输入字符 | 取消输入 |

## 7. V1 明确不做（设计里不要出现）

- PIN 家长锁（V2）
- 智能推荐 / 排序算法可视化（V2）
- 跨设备进度同步（当前 Apple TV 本地进度记录/续播已实现并完成 Debug）
- 纯音频（MP3）+ 字幕（Backlog）
- 云同步、账号系统、多用户
- 复杂设置面板
- AI 分类、AI 推荐
- 儿童自建播放列表
- 自定义播放控制条

## 8. 实现与验证要求

1. SwiftUI 实现覆盖原型中的所有 V1 页面和状态；
2. 每个页面具有明确的初始 Focus 与返回后的 Focus 恢复；
3. 遥控器方向流与原型一致；
4. 加载、封面缺失、认证失效、播放失败、空状态和无网络可验证；
5. 关键组件复用原型的色彩、圆角、间距和文字层级；
6. 系统 `AVPlayerViewController` 的技术限制优先于原型中的播放器示意层；
7. 每个开发阶段均通过构建与对应的运行验证。

## 9. 本轮已确认的设计参数

- 哄睡模式使用淡紫粉和莓果紫，与白天的浅杏黄和珊瑚橙明确区分；

- 哄睡模式默认总时长 30 分钟，曲目不循环，家长可调整；
- 播放中不显示剩余时间；
- 封面缺失时由 Apple TV 端截取生成；

- 内容适用性标签为 `daytime` / `sleep` / `both`，默认 `both`，可同时出现在两行；
- 最终视觉方向为 C「绘本果园」，采用桃乳白背景与白天/哄睡两套对齐模块色；
- 每个 shelf 独立横向滚动，Focus 自动滚入可视区域；
- 哄睡模式自然结束后自动播放下一首，每首最多一次；
- 首次配置 Back 逐步返回且不能绕过配置；
- 家长设置以文字列表为主，并提供遥控器声音反馈开关。
