# BabyPlayer

面向幼儿家庭的 Apple TV 本地媒体播放器。

核心体验：

**打开 App → 看到内容 → 点击封面 → 播放**

> 当前状态：Phase 0 — 需求分析与冻结。  
> 在需求明确冻结之前，不进入正式编码。

## 项目目标

BabyPlayer 不是通用文件播放器，也不是家庭媒体服务器。

它希望把儿童本地视频从“文件”变成孩子能够理解和选择的“内容”。
