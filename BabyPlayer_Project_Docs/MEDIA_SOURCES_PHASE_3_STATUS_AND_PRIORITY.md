# Phase 3：媒体源状态、优先级和启动选择

状态：2026-09-27 完成 tvOS 状态逻辑与启动选择；百度授权和配置入口属于后续阶段。

## 来源和状态

稳定来源值为 `samba`、`baidu`、`jellyfin`。每个来源分别为 `unconfigured`、`offline`、`online`。Samba 从已保存的连接配置及 Root Folder 实际目录读取判断；Jellyfin 从已有 Keychain 授权及音乐视频目录读取判断。百度在 Phase 5 授权闭环完成前始终为未配置，不显示虚假的已连接状态。

默认优先级为 Samba、百度、Jellyfin。家长修改后的完整顺序保存在 `BabyPlayer.MediaSourcePriority.v1`，缺项或旧格式自动补齐。旧 `BabyPlayer.ActiveMediaSource.v1` 保留以免损坏历史数据，但不再决定启动默认来源；优先级第一名就是默认候选。评分、屏蔽、续播、封面和歌词数据键没有被本阶段重写。

启动时先探测全部已配置来源，再选择最高优先级的在线来源。若初次媒体库加载失败，可以尝试下一个已探测为在线的来源。完成初次加载后以及播放过程中断线时，不做跨来源自动切换。Samba 的旧缓存可继续展示，但它本身不能证明网络在线。

## 阶段边界

Phase 4 将完善无在线来源时的三个配置入口和家长排序 UI。Phase 5 才会建立百度 OAuth、设备绑定和手机 Root Folder 页面；Phase 6 验证真实播放与 Range/seek，验证通过后 Phase 7 才正式接入。当前电视上已部署的仍是 Phase 2 版本，Phase 3 的代码尚未单独部署到电视。

## 验证

tvOS 模拟器测试：114 通过，1 项真实 Samba 测试因模拟器未注入 Keychain 密码而跳过。覆盖三来源三态、默认顺序、家长顺序持久化、旧来源偏好迁移、最高在线来源选择、单源离线回退、全部离线及播放中禁止自动切源。未改动歌词、ASR、DeepSeek 和播放器实现。
