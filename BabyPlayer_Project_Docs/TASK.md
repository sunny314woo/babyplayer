- [x] 确认 V1 媒体来源 → 局域网 Mac Mini 上的本地文件

- [x] 确认首页信息架构 → 顶部固定三个分类选项卡 + 中间两行 shelf（白天模式行 / 哄睡模式行），两行对应两种播放模式入口；选项卡切换后两行独立过滤
- [x] 确认封面比例 → 横版 16:9
- [x] 确认播放器方案 → tvOS 系统 AVPlayerViewController
- [x] 确认最小播放控制能力 → 开始播放、暂停/继续、退出、返回；V1 不记录播放进度
- [x] 确认家长设置入口 → 首页角落低调入口；V1 不加 PIN 保护
- [x] 确认分类选项卡 → 固定三个：儿歌 / 动画 / 全部；切换后两行独立过滤
- [x] 确认播放模式视觉差异 → 哄睡行使用更暖的标签色和底色，白天行保持较清爽的视觉
- [x] 确认播放结束提示 → 不显示剩余时间；循环次数或停止条件达到后直接结束
- [x] 确认设置页结构 → 使用平铺列表，不分组
- [x] 确认空状态 → 大图标面向儿童，小字说明面向家长
- [x] 确认白天模式默认参数 → 每首视频默认循环 3 次，家长可调整
- [x] 确认哄睡模式默认参数 → 默认总时长 30 分钟，曲目不循环，家长可调整
- [x] 确认封面缺失策略 → Apple TV 端从视频画面截取生成
- [x] 确认行标题 → “白天模式”“哄睡模式”保持对儿童可见
- [x] 确认家长入口 Focus 路径 → 从第二行最后一个封面按“右”到达齿轮
- [x] 确认首页 Back 行为 → 首页拦截 Back，防止儿童误退出
- [x] 确认内容适用性标签 → `daytime` / `sleep` / `both`；默认 `both`，可同时出现在两行；Jellyfin 文件夹提供初始分配，设置页提供手动兜底
