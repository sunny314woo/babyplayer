# Phase 4：首次启动和家长设置

状态：2026-09-27 完成三来源状态展示与启动优先级编辑；百度扫码动作等待 Phase 5 授权服务接入。

## 首次启动

当没有已配置且在线的来源时，首页分别显示 NAS/Samba、Jellyfin、百度网盘。NAS 可进入连接设置；Jellyfin 可进入 Quick Connect；百度入口明确标记授权服务尚未接入并禁用扫码操作。已保存但离线的 NAS/Jellyfin 显示“重连 / 修改设置”，不会把旧缓存误报为在线。

## 家长设置

“媒体源与优先级”展示三来源的未配置、离线或在线状态，并区分“当前播放”和“默认优先级”。家长可用上移/下移调整顺序，修改立即保存到 `BabyPlayer.MediaSourcePriority.v1`，不会中断当前播放。第一名是下次启动的默认候选，只有在线时才会被选中。Samba 的连接编辑入口与 Jellyfin Quick Connect 保持原有行为；百度扫码将在后端闭环就绪后启用。

## 验证与限制

tvOS 模拟器通过 115 项测试，1 项真实 Samba 联机测试因模拟器未注入密码而跳过。无配置模拟器的首次启动画面已检查三入口布局和禁用状态。以上是 Phase 4 完成时的历史状态。【MODIFIED】2026-09-28：原 Lightsail 已废弃，后端已隔离部署在现有 Hetzner；Phase 5 百度扫码入口已启用并安装到实体 Apple TV。真实百度授权与在线播放仍按后续阶段验收。
